**Jay Hambidge • The Elements of Dynamic Symmetry • semantic digital archive**

Mission
-------

``geometor/hambidge`` is part of the interconnected `GEOMETOR <https://geometor.com>`_ semantic digital archive. It liberates Jay Hambidge's pioneering formulation of *Dynamic Symmetry* from isolated print bounds into addressable semantic units, calibrated theme-adaptive vector diagrams, primary-source folio provenance, and exact symbolic models of root rectangles (:math:`\sqrt{2}, \sqrt{3}, \sqrt{4}, \sqrt{5}`), whirling squares, and golden-ratio proportions across the GEOMETOR corpus.

Books in This Archive
---------------------

- **`The Elements of Dynamic Symmetry <https://geometor.github.io/hambidge/dynamic_symmetry/>`_** — The foundational 1920 treatise establishing the geometry of dynamic rectangles, reciprocal proportions, and thematic partitioning in Greek art and nature.

Repository Contents
-------------------

- ``docsrc/`` — Book Codex tracks, apparatus registries, and Sphinx docs compiled by `PHOTON publish <https://github.com/photon-platform/publish>`_.
- ``resources/`` — Primary folio scans, structure maps, persons/citations registries, and review manifests.
- ``src/geometor/hambidge/`` — Exact root-rectangle generators, proportional partitioning scripts, and CLI helpers.
